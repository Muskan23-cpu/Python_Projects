# 🐍 Python Projects

## 📌 About This Repository

This repository contains a collection of Python projects created while learning and practicing **Python programming**. These projects helped me strengthen my understanding of programming fundamentals, problem-solving, functions, loops, conditions, data structures, and user input.

## 🚀 Projects Included

- 🎂 **Age Calculator** – Calculates a person's age based on their date of birth.
- 🏧 **ATM Simulator** – Simulates basic ATM operations such as balance checking, withdrawal, and deposit.
- 🧮 **Calculator** – Performs basic arithmetic operations.
- 📇 **Contact Book** – Stores and manages contact information.
- ⏳ **Countdown Timer** – Creates a simple countdown timer.
- 💰 **Expense Tracker** – Records and manages daily expenses.
- 🎯 **Number Guessing Game** – A game where the user tries to guess a randomly generated number.
- 🔐 **Password Generator** – Generates random and secure passwords.
- ✊ **Rock Paper Scissors** – A simple command-line game against the computer.
- 📝 **Simple Quiz Game** – Tests the user's knowledge through multiple questions.
- 🎓 **Student Grade Calculator** – Calculates students' grades based on their marks.
- ✅ **To-Do List** – Helps users add, view, and manage tasks.
